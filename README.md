# PCB 走线审阅工作台

本地运行的 PCB 走线审阅工具：可编辑的二维板图、多铜层（顶层/底层）连通关系、
网表预期与可解释的规则检查闭环。不依赖任何在线服务或账户。

## 快速开始

```bash
pip install -r requirements.txt
python3 run.py          # 打开 http://127.0.0.1:8000
```

首次启动会自动创建一块**示例板**（`demo`），打开页面即可直接操作，
板上刻意包含四种典型情况：

| 网络 | 情况 |
|---|---|
| `+5V` | 顶层走线经过孔换到底层，完整布通 |
| `GND` | 两段走线没接上，未布通 |
| `SIG_A` / `SIG_B` | 顶层平行走线净距 0.05mm，违反 0.2mm 净空 |
| `SIG_C` | 底层走线横穿 `+5V`，铜皮重叠形成短接 |

## 运行测试

```bash
python3 -m pytest tests/ -q
```

22 个测试全部走真实 API 路径（保存 → 检查 → 重新打开），覆盖：
跨层投影无过孔不导通、同层线端/焊盘边缘接触导通、网络名不代替几何连接、
净空对象对/铜层/实测距离、短接判定、版本冲突（409）、不完整设计拒绝（422）、
历史结果与版本绑定、局部修改不影响其他网络的结论。

## 使用说明

- **画布**：拖动移动对象（走线整体平移、焊盘/过孔移动）；空白处拖动平移；滚轮缩放。
  缩放只是视图变换，服务端几何结论只认 mm 坐标。
- **网络面板**：点击网络查看服务端算出的铜岛划分（顶层/底层实际连接范围），
  每个铜岛用不同颜色描边。
- **编辑**：选中对象后点"换层"切换铜层；修改净空规则输入框即改规则。
  任何编辑都会让旧检查结果从画布撤下（标记"未保存"），不会把旧问题标在新坐标上。
- **保存 / 运行检查**：保存产生新的不可变版本；检查对指定版本运行并归档。
  若设计已被另一窗口更新，保存返回 409 并弹出冲突对话框
  （加载最新版 / 强制覆盖），不会无提示覆盖。
- **检查历史**：旧版检查结果可随时回看，画布切换到该版本快照（只读），
  问题定位始终基于当时的坐标，不会悄悄指向新版对象。
- **问题详情**：点击问题，画布聚焦相关对象，侧栏显示规则、实测净距、
  所在铜层与判断依据。

## 数据模型（单位均为 mm）

```json
{
  "name": "示例板",
  "units": "mm",
  "rules": {"clearance_mm": 0.2},
  "objects": [
    {"id": "T1", "kind": "trace", "net": "+5V", "layer": "top",
     "path": [[10, 10], [30, 10]], "width": 0.5},
    {"id": "P1", "kind": "pad", "net": "+5V", "layer": "multi",
     "x": 10, "y": 10, "diameter": 1.6},
    {"id": "V1", "kind": "via", "net": "+5V", "x": 30, "y": 10, "diameter": 1.0}
  ]
}
```

- `trace`：折线 + 线宽，属于单一铜层（`top`/`bottom`）。
- `pad`：圆形焊盘，有实际直径；`layer` 为 `top`/`bottom`/`multi`（多层都有铜）。
- `via`：过孔，贯穿全部铜层。
- 对象 `id` 由前端生成并在编辑中保持稳定，检查结果通过 id 引用对象。

## 检查语义

- **连通**：同层铜皮净距离 ≤ 1e-6 mm 视为接触导通（线端碰焊盘边缘算连接）；
  跨层投影相交但没有过孔不导通；网络名相同不代替几何连接。
- **未布通（unrouted）**：同一网络的焊盘分布在多个互不相连的铜岛中。
- **净空违规（clearance）**：不同网络的对象在同一铜层净距离 < `clearance_mm`，
  报告具体对象对、所在层与实测净距。
- **短接（short）**：不同网络的铜皮接触/重叠（净距离 ≤ 0）。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/designs` | 设计列表 |
| POST | `/api/designs` | 新建设计 `{name, data?}` |
| GET | `/api/designs/{did}` | 最新版本完整设计 |
| GET | `/api/designs/{did}/versions/{v}` | 指定版本快照 |
| PUT | `/api/designs/{did}/versions` | 保存新版本 `{base_version, data}`；base 过期返回 409，设计不完整返回 422 |
| POST | `/api/designs/{did}/checks` | 对某版本运行检查 `{version?}` |
| GET | `/api/designs/{did}/checks` | 检查历史 |
| GET | `/api/designs/{did}/checks/{cid}` | 某次检查完整结果 |

## 代码结构

```
pcbworkbench/
  geometry.py   二维几何内核（胶囊/圆盘净距离，mm）
  checks.py     设计校验、铜岛连通分析、规则检查
  store.py      SQLite 持久化（设计/版本/检查结果）
  seed.py       内置示例板
  app.py        FastAPI 接口与静态页面
static/         前端单页（画布渲染、编辑、问题面板）
tests/          pytest（几何单元测试 + API 端到端测试）
run.py          本地启动入口
```
